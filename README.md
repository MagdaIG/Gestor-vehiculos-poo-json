# Gestor de Vehículos

Aplicación web para la gestión de vehículos que implementa Programación Orientada a Objetos (POO) y manipulación de JSON. Permite registrar, visualizar y administrar diferentes tipos de vehículos con sus características específicas.
## Características principales

- Sistema de clases para vehículos (Vehículo, Auto, Motocicleta, Camión)
- Manipulación avanzada de formato JSON
- Interfaz profesional con diseño responsive
- Visualización de datos tanto en consola como en pantalla
- Conversión bidireccional entre objetos JavaScript y JSON
- Diseño accesible y compatible con múltiples plataformas

## Cómo usar

1. Descarga los archivos del proyecto
2. Abre el archivo `index.html` en tu navegador web
3. Utiliza los botones disponibles para interactuar con el sistema:
  - **Mostrar en consola**: Visualiza los detalles en la consola del navegador
  - **Mostrar lista**: Presenta los vehículos en la interfaz
  - **Ver JSON**: Muestra el formato JSON de los datos
  - **Limpiar**: Restablece la visualización actual
